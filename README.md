# 电子设计竞赛项目

三人协作的电子设计竞赛共享仓库。

## 目录说明

- `hardware/`：原理图、PCB、器件资料与硬件说明
- `software/`：嵌入式程序、上位机与相关软件
- `docs/`：方案、设计文档、测试记录与项目资料
- `test/`：测试代码、测试数据与验证结果

## 协作约定

- 开始修改前先同步远端最新内容。
- 提交信息应简洁说明改动内容。
- 不提交临时文件、编译产物或包含密钥的文件。
