# work2：Wokwi 软件 PWM 呼吸灯

> 学习步骤、每关填空骨架和排错表见 **[`闯关指南.md`](闯关指南.md)**。

本目录对应课程发布的《Wokwi 第二周任务书》，周期 **2026/11/16–2026/11/23**。

> 任务书标题沿用了上周的“Wokwi 点亮 RGB 灯”，实际任务是用软件延时生成 PWM，让红灯呼吸。
> 任务书 PDF 不随公开仓库分发，请从课程平台获取。

## 任务要求

- 平台：Wokwi 在线仿真（wokwi.com）
- 开发板：Raspberry Pi Pico
- 语言：MicroPython
- 沿用上周工程：共阴 RGB 灯，红灯脚接 GP10，串 220Ω 限流电阻
- 软件 PWM：
  - 固定周期 T = 20ms（对应 50Hz），切成 N = 100 份，每份 0.2ms；
  - 每一份根据当前占空比决定输出高电平还是低电平：
    `led.value(1 if i < duty else 0)`；
  - 外层让 duty 从 0 逐步加到 100 再减回 0，红灯由暗到亮再到暗。
- 代码约束：
  - 周期 T、份数 N、每份时长写成文件开头的命名常量；
  - 亮灯判断写成一行条件表达式，不许 if/else 抄两段；
  - 最大缩进不超过三层。

## PWM 常量速查

| 常量 | 含义 | 默认值 | 换算 |
|---|---|---|---|
| `T_MS` | PWM 周期 | 20 | 20ms 对应 50Hz |
| `N` | 一个周期切成的份数 | 100 | 100 档亮度 |
| `STEP_US` | 每份时长 | 200µs | 由 `T_MS` 和 `N` 算出 |
| `DUTY_STEP` | duty 每次变化的百分点 | 1 | 越小呼吸越慢、台阶越细 |

> **0.2ms 的坑**：MicroPython 的 `time.sleep_ms()` 只处理整数毫秒。写 `sleep_ms(0.2)` 得不到 0.2ms（会报错或被当成 0），周期就失控了。参考实现用 `time.sleep_us(200)`。详见闯关指南第 5.3 节。
>
> **duty 的折算**：任务书伪代码里的 `duty` 是 0–100 的百分比。代码里先用 `on = duty * N // 100` 折算成高电平份数，再写 `1 if i < on else 0`；N = 100 时 `on` 就等于 `duty`。

## 接线表

沿用上周接线即可，本任务只用到红灯通道；绿、蓝保留不拆。

| RGB 灯引脚 | 连接 | Pico 引脚 |
|---|---|---|
| COM（公共端） | 直接接 GND（黑线） | `pico:GND.1` |
| R（红） | 串 220Ω 电阻 | `pico:GP10` |
| G（绿） | 串 220Ω 电阻（保留） | `pico:GP11` |
| B（蓝） | 串 220Ω 电阻（保留） | `pico:GP12` |

Wokwi 元件类型：

- Pico：`wokwi-pi-pico`
- RGB 灯：`wokwi-rgb-led`，**默认共阳**，必须设 `"common": "cathode"`
- 电阻：`wokwi-resistor`，`"attrs": {"value": "220"}`

## 运行方式（Wokwi 网页版）

1. 打开 <https://wokwi.com/>，登录后打开上周的 Pico + MicroPython 工程；
   如果重开新工程，就把本目录的 `diagram.json` 导入。
2. 确认红灯串 220Ω 接 GP10、COM 接 GND。
3. 把 `main.py` 粘贴到在线编辑器，先看到红灯闪烁基线。
4. 按闯关指南逐关改成 PWM，在线运行观察呼吸效果。
5. 验证通过后，把 `main.py`（和改过的 `diagram.json`）同步回本目录。
